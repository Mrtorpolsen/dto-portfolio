# Portfolio

My personal developer portfolio, built to showcase my experience, projects, and technical skills.

## About

The portfolio is built with **Next.js, React, TypeScript, and Tailwind CSS**. The goal was to create a clean and responsive site that presents my work while also serving as a practical project for experimenting with modern frontend development.

Rather than treating the portfolio as a purely static presentation, I wanted the codebase to reflect how I approach development: keeping responsibilities separated, building reusable components, and thinking about maintainability as the project grows.

## Tech Stack

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**

## Features

* Responsive design
* Project showcase
* Experience and skills overview
* Reusable React components
* Type-safe development with TypeScript
* Responsive layouts for desktop and mobile
